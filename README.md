# MOD-NSW-GMCB



Modificaciones caseras para todos


He modificado Daybreak para eliminar de una vez por todas la confusión constante entre "Solo FAT32" y "FAT32 + exFAT".

Lógicamente, si un usuario selecciona por error la opción "FAT32" cuando su tarjeta SD está formateada como exFAT, se produce el temido error: "La tarjeta SD es exFAT, pero el controlador HOS instalado solo admite FAT32".

Al eliminar la opción de solo FAT32 y forzar la instalación de ambos controladores (FAT32 + exFAT), el sistema siempre será compatible independientemente del formato de la tarjeta SD.

Este sencillo cambio resuelve el problema por completo y evita que los usuarios se encuentren con un callejón sin salida técnico.
